# Group assignment 1.3: Mind Your Step Size!

In this assignment, you will practice numerically solving initial value problems. We will model the degradation of a contaminant that sorbs non-linearly to soil.

You can preview the instructions of this assignment on https://mude.citg.tudelft.nl/workbook-2026/assignments/GA1.3/README.html. After the deadline, this link will include solutions. The preview without solutions will remain available here: https://mude.citg.tudelft.nl/workbook-2026/no_solutions/assignments/GA1.3/README.html. All files of an assignment can be downloaded as [`.zip`-file](https://mude.citg.tudelft.nl/workbook-2026/_custom_downloads/assignments/GA1.3/all_files_GA_1_3.zip) to your computer.

At 11:30, you'll have to close laptops and receive a set of questions to be solved as a group. These questions are based on what you did in the first three hours. You can make use of notes written in the first three hours, but you are not allowed to use any other resources like AI. At 12:30, you'll hand in your handwritten answers to the questions.

Before you can start this assignment, you should have read the theory in the [book](https://mude.citg.tudelft.nl/book/2026/numerical_methods/overview.html), completed the [Wednesday's workshop](https://mude.citg.tudelft.nl/workbook-2026/assignments/WS1.3/README.html) and the [programming assignment](https://mude.citg.tudelft.nl/workbook-2026/assignments/PA1.3/README.html) of this week.

In this assignment you’ll make exercises on the following topics:

- numerically solving initial value problems
- implicit methods for non-linear ODE
- multi-step methods
- stability of numerical methods
